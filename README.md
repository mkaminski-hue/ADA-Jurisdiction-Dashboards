# Illinois ADA Polling Place Accessibility Survey: dashboards

This repository hosts the jurisdiction dashboards from the State of Illinois ADA Accessibility Survey Project, published with GitHub Pages.

- `index.html`: home page listing every jurisdiction
- `<jurisdiction>/index.html`: one dashboard per county or city election authority (e.g. `city-of-bloomington/`)
- `jurisdictions.json`: the list the home page is built from
- `robots.txt`: asks search engines not to index the site (pages also carry a `noindex` tag)

Each dashboard has a drop-down to pick a polling place and shows the items that need remediation, with the surveyor's notes and measurements, plus every survey answer.

## Adding or updating a jurisdiction

The pages are generated by `ada_dashboard.py` (kept outside this repository, with the raw survey exports):

```
python ada_dashboard.py --site <this folder> <Jurisdiction export>.xlsx
```

That writes `<jurisdiction>/index.html` and rebuilds the home page. Then upload the changed files to this repository; GitHub Pages republishes in a minute or two.
